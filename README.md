# 🎓 Sobat Guru

**Sobat Guru** — Generator Prompt Perangkat Ajar untuk guru Indonesia.

Susun prompt perangkat ajar terkalibrasi Kurikulum Merdeka & Pembelajaran Mendalam, jalankan di Gemini / ChatGPT gratis milik Bapak/Ibu, lalu rapikan hasilnya jadi Word / PDF berkop surat.

Berjalan 100% di browser — tanpa server, tanpa biaya AI. Data hanya tersimpan di perangkat Anda.

## Fitur

1. **📄 Modul Ajar** — susun prompt Modul Ajar lengkap (11 komponen, 3 prinsip pembelajaran: berkesadaran, bermakna, menggembirakan, dan 8 Dimensi Profil Lulusan)
2. **🗺️ Analisis CP–TP–ATP** — susun prompt analisis Capaian Pembelajaran → Tujuan Pembelajaran → Alur Tujuan Pembelajaran, hasilnya bisa dipakai ulang untuk dokumen berikutnya
3. **🎯 Soal & Rubrik** — susun prompt soal + kisi-kisi + rubrik + kunci jawaban
4. **✨ Perapi Dokumen** — tempel hasil mentah dari Gemini/ChatGPT, render jadi dokumen rapi, lalu unduh sebagai **Word (.doc)** atau cetak / simpan **PDF**, lengkap dengan kop surat sekolah dan blok tanda tangan

Semua prompt disusun mengikuti format **Permendikdasmen No. 13 Tahun 2025**.

## Cara Pakai (3 Langkah)

1. Isi data umum & formulir dokumen yang mau dibuat, lalu klik **Susun Prompt**
2. Klik **Buka di ChatGPT** atau **Buka di Gemini** — prompt terisi otomatis / tersalin, tinggal Enter dan tunggu AI menyusun dokumennya
3. Salin hasil dari AI, tempel di menu **Perapi Dokumen** → unduh sebagai Word / PDF rapi lengkap dengan kop surat sekolah

## Teknologi

- 1 file `index.html` (HTML + CSS + Vanilla JavaScript), tanpa build, tanpa dependensi
- Data umum & kop surat tersimpan otomatis di `localStorage` perangkat pengguna
- Cocok di-hosting statis apa pun, termasuk GitHub Pages

## Catatan

Hasil akhir dari AI selalu perlu ditelaah guru sebelum digunakan di kelas.
